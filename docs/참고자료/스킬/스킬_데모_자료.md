# Claude Code 스킬(Skill) 데모 자료

> 최종 업데이트: 2026-03-25

자문기관 전달용. MVP 기능을 Claude Code 스킬로 구현한 결과와 설명.

---

## 스킬이란?

AI에게 특정 작업의 절차와 품질 기준을 **마크다운 문서 한 장**으로 정의해두면, 사용자가 자연어로 요청하는 것만으로 AI가 그 절차를 따라 직접 수행하는 방식입니다.

**프로그래밍이 필요 없습니다.** CLI(명령줄 인터페이스) 환경에서 자연어로 지시하면 AI가 스킬 문서를 작성하고, 테스트하고, 개선점을 찾아 수정까지 합니다. CLI 환경의 기본적인 사용법(터미널 열기, 명령어 입력)만 알면 누구나 자기 업무를 스킬로 만들 수 있습니다.

## 스킬 1: pdf-to-markdown (MVP 1 대응)

### 기능
PDF 문서를 Claude의 비전(Vision) 능력으로 직접 읽어 고품질 마크다운으로 변환

### 만드는 과정
Claude Code에서 이렇게 말했습니다:
> "MVP 1의 PDF 변환 기능을 스킬로 만들어줘. 계층 구조를 살리고, 각주는 인용 블록으로 처리하고, 페이지 번호는 제거해"

AI가 스킬 문서를 작성 → 실제 PDF로 테스트 → 출력 품질 비교 → 개선점 반영까지 자동으로 수행했습니다.

### 사용법
Claude Code에서:
```
이 PDF를 마크다운으로 변환해줘
```
이 한 마디면 됩니다.

### 변환 품질 비교 (같은 PDF 기준)

| 방식 | 띄어쓰기 | 표 구조 | 계층(헤딩) | 각주 | 다이어그램 | 품질 |
| :--- | :--- | :--- | :--- | :--- | :--- | ---: |
| AI 없는 텍스트 추출 (pypdf) | 대부분 소실 | 평탄화 | 없음 | 섞임 | 누락 | ~55점 |
| MVP 도구 (Gemini Vision) | 정상 | 마크다운 표 | 있음 | 불릿과 혼재 | 리스트화 | ~90점 |
| Claude 스킬 (Vision OCR) | 정상 | 마크다운 표 | 정확 | 인용블록 분리 | 흐름 표현 | ~95점 |

### 핵심 개선점
MVP 도구에서 모든 항목이 불릿(`-`)으로 평탄화되어 본문·각주·페이지번호의 구분이 사라지는 문제를, 스킬에서는 계층 구조 규칙으로 해결. 이 분석 결과를 역으로 MVP 도구의 OCR 프롬프트에도 반영하여, GUI 도구의 변환 품질도 함께 개선했습니다.

## 스킬 2: (향후 구현 가능 — MVP 2 대응)

문서 분할 및 테마별 자동 큐레이션. MVP 2 기능이 GUI 도구에서 안정적으로 동작하고 있어, 스킬로의 전환 우선순위는 낮음.

---

## 스킬 3: (향후 구현 가능 — MVP 3 대응)

교육과정 데이터 재구조화 및 핵심 내용 분석. MVP 3 역시 GUI 도구에서 2단계 요약(Step1 개별 요약 → Step2 통합 분석)이 구현 완료되어, 필요 시 스킬로 전환 가능.

---

## GUI 도구와 스킬의 관계

| 구분 | GUI 통합 도구 | Claude Code 스킬 |
| :--- | :--- | :--- |
| **적합한 상황** | 대량 배치 처리 (수십~수백 파일) | 소량 고품질 변환 (1~수 개 파일) |
| **필요 환경** | Tauri 데스크톱 앱 (MSI) + Gemini API 키 | Claude Code 구독 |
| **프로그래밍 필요** | 불필요 (GUI 클릭) | 불필요 (자연어 지시) |
| **커스터마이징** | 설정 파일(YAML) 수정 | 스킬 문서(마크다운) 수정 |
| **확장성** | 코드 수정 필요 | 자연어로 규칙 추가 |

두 방식은 상호 보완적입니다. 스킬에서 발견한 품질 개선점을 GUI 도구에 역반영하고, GUI 도구의 배치 처리 결과를 스킬로 후보정하는 식의 워크플로우가 가능합니다.
