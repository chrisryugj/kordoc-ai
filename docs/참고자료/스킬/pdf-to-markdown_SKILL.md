# PDF to Markdown Converter

PDF 문서를 Claude Vision으로 직접 읽어 고품질 마크다운으로 변환하는 스킬입니다.

## 사용 시나리오

- PDF 파일을 마크다운 문서로 변환
- 스캔된 문서의 OCR 및 구조화
- 공문서, 보고서, 기획서 등의 디지털 전환
- 표, 도해, 순서도가 포함된 복잡한 문서 변환

## 처리 워크플로우

### Step 1: PDF → 이미지 변환

PyMuPDF로 PDF의 각 페이지를 이미지(PNG)로 변환합니다.

```python
import fitz
doc = fitz.open(pdf_path)
for i in range(len(doc)):
    page = doc[i]
    pix = page.get_pixmap(dpi=200)
    pix.save(f'/tmp/pdf_page_{i+1:03d}.png')
doc.close()
```

- DPI: 200 (품질과 속도의 균형)
- 출력: `/tmp/pdf_page_NNN.png`

### Step 2: 이미지 → 마크다운 변환 (Vision OCR)

Read 도구로 각 이미지를 읽어 비전 능력으로 직접 OCR합니다.
한 번에 3~5페이지씩 병렬로 읽을 수 있습니다.

### Step 3: 변환 품질 규칙

다음 규칙을 **반드시** 준수하여 마크다운을 작성합니다:

#### 계층 구조 (가장 중요)

- 제목/소제목은 `#`, `##`, `###` 헤딩 사용
- 본문은 **불릿 없이 일반 문단**으로 작성
- 원본에 `◦`, `○`, `•` 등 명시적 기호가 있는 항목만 불릿(`-`)으로 변환
- 괄호로 시작하는 본문 항목은 **볼드 키워드 문단**으로:

**잘못된 예:**
```
- **(AI 전환 가속화 대응)** 정부 및 공공기관의...
```

**올바른 예:**
```
**(AI 전환 가속화 대응)** 정부 및 공공기관의...
```

#### 각주 처리

본문의 `*`, `**` 표시 각주는 **절대 불릿으로 변환하지 않음**.
인용 블록(`>`)으로 분리:

```
> *주) MVP(Minimum Viable Product): 최소한의 핵심 기능으로...
```

여러 각주가 있을 때:
```
> *주1) 첫 번째 각주 내용
> *주2) 두 번째 각주 내용
```

#### 표(Table)

- 모든 행과 열을 빠짐없이 마크다운 표로 변환
- 셀 안에 여러 줄이 있으면 쉼표나 세미콜론으로 연결하여 한 셀 유지
- 정렬: 숫자 열은 우측 정렬(` ---: `), 텍스트는 좌측(` :--- `)

#### 페이지 번호

- `- 1 -`, `- 2 -` 등 페이지 하단의 쪽번호는 **제거**
- 대신 `[[PAGE: N]]` 마커를 각 페이지 시작에 삽입

#### 다이어그램/순서도

단순 리스트 대신 흐름 관계를 표현:
```
1. **시작**
2. **PDF → 이미지 변환** (150 DPI)
3. **병렬 처리 구간** (Thread, MAX_WORKERS=4)
   - 조건? → [Yes] 처리A / [No] 처리B
```

#### 강조 박스

색상 배경이나 테두리로 강조된 텍스트는 인용문(`>`)으로:
```
> ☞ 자문을 통해, '26년 하반기 AI 전환 본격 가동을 위한...
```

#### 절대 금지

- HTML 태그 (`<br>`, `<table>` 등)
- 마크다운 코드블록으로 결과 감싸기 (` ```markdown `)
- `\*` 이스케이프 (각주에서 특히 주의)
- "결과입니다", "변환 완료" 등의 메타 설명

### Step 4: 통합 및 저장

- 각 페이지를 `---` 구분선으로 연결
- 확장자: `.md`
- 인코딩: UTF-8
- 저장 경로: 원본 PDF와 같은 디렉토리

## 출력 형식

```markdown
[[PAGE: 1]]

# 문서 제목

< 날짜, 부서명 >

## 1 첫 번째 섹션

**(키워드)** 본문 내용이 이어집니다...

> *주) 각주 내용

---

[[PAGE: 2]]

## 2 두 번째 섹션

| 열1 | 열2 | 열3 |
| :--- | :--- | ---: |
| 데이터 | 데이터 | 숫자 |
```

## 주의사항

- 대용량 PDF(20p+)는 5페이지씩 나눠서 처리
- 이미지 전용 페이지(사진, 도면)는 `[이미지: 설명]` 형태로 표시
- 개인정보가 포함된 경우 사용자에게 알림
