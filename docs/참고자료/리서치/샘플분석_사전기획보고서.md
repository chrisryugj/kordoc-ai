## 2. PDF1: 사전기획 보고서 예시 도움자료 (84p)

- **정의**: 17개 시·도교육청이 사전기획을 체계적으로 추진하기 위해 마련한 **표준 보고서 양식/예시**

## 3. PDF2: 검토의견서 샘플 (8p)

### 3.1 문서 성격
- **정의**: 사전기획 보고서를 **전문가가 검토한 결과** 문서
- **용도**: 이것이 바로 교육시설안전원 사전기획팀이 **일일이 수작업으로 만드는 문서**
- **형태**: 표 기반 + 텍스트 검토의견 (모든 페이지가 표+이미지 혼합)
- **핵심**: 보고서(PDF1)의 각 항목을 **적정/보완권고/보완** 판정 + 상세 의견 기술

### 3.2 검토의견서 구조

```
■ 사업추진에 관한 사항 (p.1~3)
  ├─ 대상학교 사업 전·후 현황 (표)
  ├─ 학교신설비 교부기준 면적 (표)
  ├─ 17개 시·도 학교급별 현황 (표)
  ├─ 사업비 산정 검토의견
  │   ├─ 총공사비 (산업안전보건법 §67)
  │   ├─ 설계VE (건설기술진흥법)
  │   ├─ 설계용역비 (건축사법 §19의3)
  │   ├─ 인증대상 (제로에너지, 녹색건축, BF)
  │   └─ 사업기간 (단계별 기간 적정성)
  └─ 사업유형 판정

■ 교육과정 등에 관한 사항 (p.4)
  ├─ 사용자 참여 (교육분야/공간분야)
  ├─ 교육 현황조사
  └─ 판정: 적정 / 보완권고 / 보완 / 해당없음

■ 건축 및 안전 등에 관한 사항 (p.5~7)
  ├─ 주변시설 여건
  ├─ 통학로 현황
  ├─ 안전보건대장
  ├─ 안전관리계획수립
  ├─ 건축물의 공간계획
  │   ├─ 외부 동선 계획
  │   ├─ 내부 동선 계획
  │   ├─ 감염병 예방 설계
  │   └─ 범죄예방 환경설계 (CPTED)
  └─ 규모계획 (면적 비율 산정표)

■ 주요설계지침 (p.8)
  └─ 사업비·면적·프로그램 총괄표
```

### 3.3 검토의견 패턴 분석

검토의견은 다음 **반복 패턴**으로 작성됨:

```
(주제키워드) 현황 설명 + 근거법령(「법명」 제N조) +
보고서 참조(보고서 p.XX~YY) +
→ 구체적 보완/확인 요청 사항
```

예시:
> (총공사비) 총공사비 100억 이상 건설공사의 경우 「건설기술진흥법 시행령」 제75조에 따른
> 설계VE 대상에 해당함에 따라, VE 관련 비용(22백만원)에 대한 구체적인 산출근거 및 기준 제시 필요
> (사업계획서 p.2, 보고서 p.116, 설계공모지침서 p.4)

## 5. MVP1 실제 처리 능력 검증

### 5.1 PDF1 (84p 보고서) 예상 처리

```
처리 방식: 84페이지 → 5개 청크 (20p씩) → Gemini Vision OCR
예상 시간: 84페이지 × ~5초/페이지 ÷ 3워커 = ~2.5분
API 비용: 84 × gemini-3-flash-preview 이미지 토큰 ≈ 소량

예상 이슈:
1. 표(table) → Gemini Vision은 표를 마크다운 테이블로 잘 변환
2. 도면/배치도 → 텍스트 추출 한계, 설명 텍스트만 추출 가능
3. 페이지 번호 "- 006 -" 형식 → text_cleaner가 제거
4. 목차 → 잘 처리됨
```

### 5.2 PDF2 (8p 검토의견서) 예상 처리

```
처리 방식: 8페이지 → 1개 청크 → Gemini Vision OCR
예상 시간: 8 × ~5초/페이지 ÷ 3워커 = ~15초
API 비용: 매우 소량

예상 이슈:
1. 표 안의 셀 병합 → Gemini Vision이 대체로 잘 처리
2. 체크마크(✓, ●) → OCR에서 일부 누락 가능
3. 법령 인용 (「」) → 잘 보존될 것
4. 페이지 참조 (p.XX~YY) → 잘 보존될 것
```

### 5.3 MVP2 연계 가능성

PDF1(보고서)의 구조가 **3대 영역 + 하위 섹션**으로 명확하므로:
- pages.xlsx에 보고서의 섹션별 페이지를 매핑하면
- MVP2로 주제별 페이지 추출 가능
- 예: "사업비" 주제 → p.14~15, "교육현황" 주제 → p.20~25

### 5.4 MVP3 연계 가능성

PDF1을 MVP1로 OCR한 결과물(.md)을 MVP3의 입력으로 사용 가능:
- 보고서 내 교육과정 섹션(2장)을 MVP3으로 요약/분석
- 여러 학교의 보고서를 모아 통합 분석

## 6. 활용 제안

### 즉시 활용 (현재 MVP)

| 순서 | 작업 | MVP |
|------|------|-----|
| 1 | PDF1(84p)을 MVP1로 OCR → 마크다운 변환 | MVP1 |
| 2 | PDF2(8p)를 MVP1로 OCR → 검토의견서 구조 학습 | MVP1 |

| 4 | OCR 결과에서 교육과정 부분을 MVP3로 분석 | MVP3 |

### 장기 활용 (자문 제안)

1. **검토의견서 자동 생성**: 보고서(PDF1) → OCR → AI 분석 → 검토의견서(PDF2 형식) 자동 생성
2. **법규 자동 매칭**: 보고서 내용에 관련 법규를 자동으로 매칭하여 검토 포인트 추출
3. **외부 데이터 연동**: URL 목록의 사이트에서 자동으로 데이터 수집 → 보고서 데이터와 교차 검증
