## 2. 사이트별 상세 분석

### 2.1 학교알리미 (★★★★★ — MVP3 입력자료 자동 수집)
- **검색 필드**: `input[name=SEARCH_KEYWORD]` — 학교명+공시항목 검색 가능
- **활용**: 교육과정 자료, 학생수, 학급수 등 공시정보 자동 수집
- **자동화 시나리오**:
  ```
  1. 학교명 검색 → 결과 목록에서 선택
  2. 공시항목별 데이터 추출
  3. MVP3 입력자료(txt)로 자동 변환
  ```
- **난이도**: 쉬움 (표준 HTML form)

### 2.2 인구통계 (★★★★☆ — 학령인구 자동 수집)
- **메뉴 구조**: 행정동별 → 연령별 인구현황, 인구증감 등
- **활용**: 학령인구 변화 추이 데이터 자동 다운로드
- **자동화 시나리오**:
  ```
  1. 연령별 인구현황 메뉴 진입
  2. 지역(시/군/구) 선택
  3. 연도 범위 설정
  4. 데이터 다운로드 (Excel/CSV)
  ```
- **난이도**: 중간 (메뉴가 JS로 구현, 클릭 순서 중요)

### 2.3 설계대가 산출 (★★★★★ — 계산 자동화)
- **폼 구조**: 1개 form, 14개 입력요소
  - `bangsik` (방식): radio 3개
  - `jongbyeol` (종별): radio 3개
  - `geubsu` (급수): radio 3개
  - `pay` (대가): text input
- **활용**: 건축사 설계대가를 자동 계산
- **자동화 시나리오**:
  ```
  1. 방식/종별/급수 라디오 선택
  2. 대가 금액 입력
  3. 산출 버튼 클릭
  4. 결과 추출
  ```
- **난이도**: 쉬움 (단순 폼)

### 2.4 세움터 (★★★☆☆ — 건축물대장)
- **제약**: 로그인/공인인증서 필요 시 자동화 한계
- **활용**: 건축물대장 열람 (면적, 용도, 건축년도 등)
- **난이도**: 어려움 (인증 절차)

### 2.5 토지이음 / 유산정보 / 학구도 (★★★☆☆ — GIS 기반)
- **공통 제약**: 지도 기반 인터페이스 → 좌표/주소 기반 검색 필요
- **활용**: 토지정보, 문화유산 존재여부, 학구도 확인
- **난이도**: 중간~어려움 (GIS API 직접 호출이 더 효율적)

## 3. 자동화 도구 평가

### browser-use CLI (가이드 기반)
- **상태**: 가이드 문서(`.claude/prompts/browser-use-cli-guide.md`)는 존재하나, 해당 CLI 도구(`browser-use open/state/click...`)는 공개 npm 패키지로 배포되지 않음
- **대안**: `browser-use-cli@1.2.1` (Chrome Extension 기반, 다른 도구) 또는 **Playwright** 직접 사용
- **결론**: 가이드의 `browser-use` 명령어는 현재 사용 불가. Playwright로 동일 기능 구현 가능

### Playwright (실제 테스트에 사용)
- **버전**: 1.58.0 (Python)
- **결과**: 7개 사이트 모두 접근 성공, 스크린샷 캡처 성공
- **장점**: headless/headed 모두 지원, DOM 조작 용이, 안정적
- **추천**: MVP의 보조 도구로 Playwright 기반 자동 수집 스크립트 구현 가능
