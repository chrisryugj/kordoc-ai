## MVP 개선 구현체 설계

### 배포 형태 (현행화: Tauri로 변경)
- ~~**통합 1개 CLI exe**: PyInstaller로 단일 .exe 빌드~~ → **Tauri MSI 인스톨러**
- React 19 GUI에서 MVP1/2/3 + 브라우저 도구 통합
- 설정 모달에서 Gemini API 키 입력 → .env 자동 저장 → 이후 자동 로드
- config/settings.yaml 만 수정하면 바로 사용 가능
- Windows 환경 타겟 (상대방 환경)

### 폴더 구조

### 핵심 개선 포인트 (기존 대비)

| 개선 항목 | 기존 MVP | 개선 구현체 |
|-----------|----------|-------------|
| 경로 관리 | `D:\mvp_1` 하드코딩 | `config/settings.yaml`에서 로드 |
| 에러 처리 | bare except, broad except | 구체적 예외 분리 + 실패 카운트 |
| 로깅 | 콘솔만 | 파일+콘솔 동시 (실행 이력 보존) |
| 메모리 | PDF 전체 한번에 로드 | 청크 단위 처리 (first_page/last_page) |
| 결과 추적 | 없음 | Result 객체 (성공/실패/경고 누적) |
| 설정 분리 | 코드에 혼재 | YAML 규칙 파일 독립 |
| 재사용성 | MVP별 독립 | shared/ 공통 모듈 |
| 실행 진입점 | 파일별 개별 실행 | 통합 CLI (python -m mvp1_converter) |

## 글쓰기 원칙

1. **AI 냄새 제거**: "~것입니다" 반복 금지. "~거든요", "~더라고요" 자연스러운 경험담 톤

6. **출처 인용**: 핵심 논거에 각주 스타일 (과도하지 않게)
7. **겸손 + 확신**: "정답은 아닐 수 있지만, 걸어본 길이기에 말씀드립니다"
