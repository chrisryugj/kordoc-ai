# MVP 개선판 프로덕션급 발전 계획서

## 현재 상태 (2026-03-25 업데이트)

~~MVP 개선 구현체 v3 (Tkinter GUI, 2026.03.21)~~ → **Tauri v2 + React 19로 전면 마이그레이션 완료**.

- Tauri 2.10 + React 19 + TypeScript 5.9 + Tailwind CSS 4 데스크톱 앱
- Python Sidecar (JSON-RPC 2.0, 18개 RPC 메서드)
- 3개 MVP + 7종 브라우저 도구 통합
- **8차 프로덕션급 코드 리뷰 완료** (안정성·UX·보안 강화)
- Gemini SDK `google.genai`로 마이그레이션 완료
- Poppler 의존성 제거 (PyMuPDF로 대체)

**아래 계획은 원본(Tkinter 기준)을 유지하되, 진행 상태를 표기함.**

## Phase 1: 버그 제거 + 안정화 (1주)

### 1-1. 코드 리뷰 + 정적 분석

| 작업 | 상세 | 우선순위 |
|------|------|----------|
| mypy 타입 체크 | 전 모듈 type annotation 추가 + mypy strict 통과 | P1 |
| ruff 린트 | ruff check --fix 적용, 코드 스타일 통일 | P1 |
| 에러 경로 전수 검사 | 모든 try-except 블록의 에러 전파 경로 확인 | P1 |
| 경쟁 조건(race condition) | 스레드 간 shared state 점검 (특히 _running 플래그) | P2 |

### 1-2. 테스트 보강

| 작업 | 상세 | 우선순위 |
|------|------|----------|
| MVP 1 온라인 테스트 | 실제 Gemini API 호출 → OCR 결과 검증 (3페이지 테스트 PDF) | P1 |
| MVP 3 온라인 테스트 | Step 1 요약 + Step 2 통합 → 리포트 생성 검증 | P1 |
| 대용량 PDF 테스트 | 100+ 페이지 PDF로 청크 처리 + 메모리 모니터링 | P1 |
| API 에러 시뮬레이션 | 429/500/타임아웃 상황 재현 → 재시도 로직 검증 | P2 |
| 엣지 케이스 | 빈 PDF, 손상 파일, 0바이트 txt, 비정상 엑셀 등 | P2 |
| GUI 자동 테스트 | 버튼 클릭 시뮬레이션, 경로 미입력 등 UX 경로 | P3 |

### 1-3. 크리티컬 버그 후보

| 의심 사항 | 확인 방법 |
|-----------|-----------|
| GUI 스레드에서 Tkinter 위젯 직접 접근 | `after()` 호출 누락 없는지 전수 확인 |
| settings.yaml 동시 읽기/쓰기 | 실행 중 설정 저장 시 충돌 가능성 |
| load_config LRU 캐시 | cache_clear() 타이밍이 적절한지 |
| Windows 경로 인코딩 | 한글 폴더명 + PyInstaller exe 조합 테스트 |
| Poppler 미설치 시 에러 메시지 | 사용자 친화적 안내가 나오는지 |

## Phase 2: 기능 완성도 (2주)

### 2-1. MVP 1 고도화

| 작업 | 상세 |
|------|------|
| HWP 없이 PDF만 처리 모드 | HWP 변환 건너뛰기 옵션 (이미 PDF만 있는 경우) |
| OCR 품질 지표 | 페이지별 텍스트 길이/신뢰도 표시, 빈 페이지 경고 |
| 프롬프트 A/B 테스트 | ocr-rules.yaml에 프롬프트 변형 → 품질 비교 |
| 비용 추정 | 처리 전 예상 토큰 수 → 예상 비용 안내 |

### 2-2. MVP 2 고도화

| 작업 | 상세 |
|------|------|
| 엑셀 매핑 GUI 편집 | settings.yaml 대신 앱 안에서 source_files/topic_folders 편집 |
| 라벨 위치 자동 조정 | 페이지 크기 읽어서 기존 콘텐츠와 겹치지 않게 |
| 미리보기 | 추출 전 어떤 페이지가 뽑힐지 트리뷰로 표시 |

### 2-3. MVP 3 고도화

| 작업 | 상세 |
|------|------|
| 대량 학교 대응 | 30개+ 학교 시 Step 2 입력이 토큰 한도 초과 → 청크 분할 로직 |
| 리포트 포맷 선택 | 마크다운 / HTML / DOCX 출력 옵션 |
| 프롬프트 커스터마이징 GUI | Step 1/Step 2 프롬프트를 앱에서 직접 편집 |

### 2-4. GUI 고도화

| 작업 | 상세 |
|------|------|
| 프로그레스 바 | 파일/페이지 단위 진행률 표시 |
| 작업 취소 | 실행 중 [중단] 버튼으로 안전 종료 |
| 결과 폴더 열기 | 완료 후 [폴더 열기] 버튼 |
| 다크 모드 | 전체 UI 다크/라이트 토글 |
| 로그 필터링 | ERROR만 보기, 검색 등 |
| DPI 스케일링 | 고해상도 모니터 대응 (tkinter dpi awareness) |
