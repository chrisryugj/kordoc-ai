# 단축키

앱에서 쓰는 단축키를 화면별로 모았습니다. 맥에서는 Ctrl 대신 ⌘를 누르는 키가 많습니다. 한글 편집기 안의 한컴식 단축키는 맥에서도 Control 키를 씁니다.

## 어디서나

| 키 | 하는 일 |
| --- | --- |
| Ctrl+O | 파일 열기. 문서 보기에서 엽니다. PDF 작업 화면에서는 책상에 넣습니다 |
| Ctrl + 더하기(=) | 화면 크게 |
| Ctrl + 빼기(-) | 화면 작게 |
| Ctrl+0 | 화면 크기 100%로 |
| Ctrl+V (입력칸 밖에서) | 그림이나 10자 넘는 글을 파일로 저장해 문서 보기에서 엽니다 |
| ↑·↓ (왼쪽 메뉴에서) | 메뉴 항목을 옮겨 다닙니다 |
| Tab (맨 처음) | "본문으로 이동"으로 메뉴를 건너뜁니다 |

화면 크기는 90%, 100%, 110%, 125%, 150% 단계로 바뀌고 다음에 켤 때도 그대로입니다.

## 창·메뉴

| 키 | 하는 일 |
| --- | --- |
| Esc | 열린 창·메뉴 닫기 |
| Tab / Shift+Tab | 열린 창 안에서만 옮겨 다닙니다 |
| ↑·↓ (우클릭 메뉴) | 항목 옮기기 |
| Enter (시작 준비 창 글자 칸) | 다음 단계로 |
| ←·→ (문서 보기 도구 탭, 편집 보조 탭) | 탭 옮기기 |
| Space·Enter, 화살표, Space·Enter (순서 목록) | 항목 들기, 옮기기, 내려놓기. Esc는 옮기기 그만두기 |

## 입력칸

| 키 | 하는 일 |
| --- | --- |
| Enter | 보내기·묻기 (AI에게 맡기기, AI 대화, 문서에 묻기, 이 문서에 묻기, 편집기 AI 대화) |
| Shift+Enter | 줄바꿈 |
| Enter / Esc (대화·프롬프트 이름 바꾸기) | 저장 / 그만두기 |
| Enter (여러 문서에서 찾기의 찾을 낱말) | 바로 찾기 |

한글을 조합하는 중에는 Enter를 보내기로 받지 않습니다.

## 문서 보기 › 미리보기에서 눌러 고치기

| 키 | 하는 일 |
| --- | --- |
| Ctrl+Z | 되돌리기 |
| Ctrl+Y 또는 Ctrl+Shift+Z | 다시 실행 |
| Ctrl+S | 저장 |
| Enter (문단 고치기) | 적용 (줄바꿈은 Shift+Enter) |
| Ctrl+Enter (표 칸 고치기) | 적용 |
| Esc | 고치는 칸 닫기. 칸이 없으면 창 닫기 |

## PDF 합치기·나누기

한글 입력 상태에서도 됩니다.

| 키 | 하는 일 |
| --- | --- |
| ←·→·↑·↓ | 쪽 옮겨 다니기(그 쪽만 고름) |
| Shift+화살표 | 범위 고르기 |
| Ctrl+화살표 | 고른 것은 두고 옮겨 다니기 |
| Home / End | 첫 쪽 / 끝 쪽 |
| Space | 쪽 고르기·풀기 |
| Enter | 크게 보기 |
| R / Shift+R | 오른쪽 / 왼쪽으로 90도 돌리기 |
| Delete 또는 Backspace | 고른 쪽 지우기 |
| Alt+← 또는 Alt+↑ | 한 칸 앞으로 옮기기 |
| Alt+→ 또는 Alt+↓ | 한 칸 뒤로 옮기기 |
| Ctrl+A | 모두 고르기 |
| Ctrl+D | 복제 |
| Esc | 고르기 풀기(끌기 중이면 끌기 취소) |
| Ctrl+S | PDF 하나로 저장 |
| Ctrl+Z | 되돌리기 |
| Ctrl+Shift+Z 또는 Ctrl+Y | 다시 하기 |

마우스

| 동작 | 하는 일 |
| --- | --- |
| 누르기 / Ctrl+누르기 / Shift+누르기 | 하나 고르기 / 더하기·빼기 / 범위 고르기 |
| 빈 곳에서 끌기 | 상자로 고르기 |
| 쪽 끌기 | 옮기기 |
| 두 번 누르기 | 크게 보기 |
| 우클릭 | 쪽 메뉴 |
| 쪽 사이 가위 | 나눌 곳 정하기·풀기 |

크게 보기 창: ←·↑ 앞 쪽, →·↓ 다음 쪽, R·Shift+R 돌리기, Delete 이 쪽 지우기, Esc 닫기.

## 한글 편집기 (새로 쓰기)

편집기 글 칸에 커서가 있을 때 됩니다. 한글·영문 입력 상태와 관계없습니다. "Ctrl+N, T"는 Ctrl+N을 눌렀다 뗀 뒤 T를 누르는 두 단계 키입니다. 두 번째 키를 누르기 전에 Esc를 누르면 그만둡니다.

저장·되돌리기

| 키 | 하는 일 |
| --- | --- |
| Ctrl+S, Alt+S | 저장 |
| Ctrl+Z | 실행 취소 |
| Ctrl+Shift+Z | 다시 실행 |

넣기 (Ctrl+N, …)

| 키 | 하는 일 |
| --- | --- |
| Ctrl+N, T | 표 만들기 |
| Ctrl+N, N | 각주 |
| Ctrl+N, E | 미주 |
| Ctrl+N, I | 그림 |
| Ctrl+N, B | 글상자 |
| Ctrl+N, M | 수식 |
| Ctrl+N, C | 캡션 넣기 |
| Ctrl+N, H | 머리말/꼬리말 |
| Ctrl+N, S | 감추기 |
| Ctrl+N, G | 구역 |
| Ctrl+N, A | 표 나누기 |
| Ctrl+N, Z | 표 붙이기 |
| Ctrl+N, F | 계산식 |
| Ctrl+N, K | 고치기(개체·셀 속성, 하이퍼링크, 필드) |

입력 (Ctrl+K, …)·찾기 (Ctrl+Q, …)

| 키 | 하는 일 |
| --- | --- |
| Ctrl+K, D | 날짜/시간 문자열(예: 2026년 10월 25일) |
| Ctrl+K, H | 하이퍼링크 |
| Ctrl+K, B | 책갈피 |
| Ctrl+K, E | 필드 입력 |
| Ctrl+Q, F 또는 F2 | 찾기 |
| Ctrl+Q, A 또는 Ctrl+H | 찾아 바꾸기 |
| Ctrl+F10 | 문자표 |

글자 색 (Ctrl+M, …)

| 키 | 색 |
| --- | --- |
| Ctrl+M, K | 검정 |
| Ctrl+M, R | 빨강 |
| Ctrl+M, B | 파랑 |
| Ctrl+M, D | 자주 |
| Ctrl+M, G | 초록 |
| Ctrl+M, Y | 노랑 |
| Ctrl+M, C | 청록 |
| Ctrl+M, W | 흰색 |

| 키 | 하는 일 |
| --- | --- |

| Ctrl+G, P | 쪽 맞춤 |
| Ctrl+G, W | 폭 맞춤 |
| Ctrl+G, Q | 100% |

| --- | --- |
| Alt+Shift+B | 진하게 |
| Alt+Shift+I | 기울임 |
| Alt+Shift+U | 밑줄 |
| Alt+Shift+P | 위첨자 |
| Alt+Shift+S | 아래첨자 |

Ctrl+Y는 한글처럼 한 줄 지우기입니다. 다시 실행은 Ctrl+Shift+Z를 쓰세요.

### 표 안에서

표 키는 본문의 표(표 안의 표 제외)에서만 됩니다. 표 밖에서는 같은 키가 원래 일을 합니다(예: Ctrl+Enter는 쪽 나누기).

커서가 표 칸 안에 있을 때

| 키 | 하는 일 |
| --- | --- |
| Ctrl+Enter | 줄 추가(아래에) |
| Ctrl+Backspace | 줄 지우기 |
| Alt+Insert | 줄/칸 추가하기 |
| Ctrl+Tab | 표 안에서 탭 넣기 |
| Ctrl+Shift+H | 가로 합계 |
| Ctrl+Shift+V | 세로 합계 |
| Ctrl+Shift+J | 가로 평균 |
| Ctrl+Shift+B | 세로 평균 |
| Ctrl+Shift+K | 가로 곱 |
| Ctrl+Shift+N | 세로 곱 |

쉬운 계산식은 결과 값만 씁니다. 칸 값이 바뀌어도 다시 계산되지 않으니 값을 고친 뒤에는 다시 누르세요.

칸 여러 개를 고른 상태(F5 셀 블록)일 때

| 키 | 하는 일 |
| --- | --- |
| F7 | 칸 전체(세로줄) 고르기 |
| F8 | 줄 전체 고르기 |
| W | 셀 너비를 같게 |
| P | 표/셀 속성 |
| L | 각 셀마다 적용: 테두리 |
| C | 각 셀마다 적용: 배경 |
| B | 하나의 셀처럼 적용: 테두리 |
| F | 하나의 셀처럼 적용: 배경 |
| Ctrl+E | 셀 내용 지우기 |
| Ctrl+Shift+A | 블록 평균 |
| Ctrl+Shift+P | 블록 곱 |
| Enter | 셀 편집 상태로 |
| Shift+Esc | 표 빠져나가기 |

칸 안 키(합계·평균·줄 추가 등)도 셀 블록에서 그대로 됩니다.

표 전체를 고른 상태(칸 안에서 Esc)일 때

| 키 | 하는 일 |
| --- | --- |
| P | 개체 속성 |
| L | 선 모양 |
| C | 배경 |
| Ctrl+E | 표 지우기 |

편집기 메뉴에 적힌 단축키도 위와 같은 한컴식으로 바꿔 두었습니다.
