## 3. 수요조사서 초안 (서무 부문)

**과제명(안)**: 서무 문서 업무 AI 비서 「KorDoc AI」: 한글 공문서 작성·편집·출력과 취합·개인정보 가림을 폐쇄망 PC 한 대에서

**현황과 문제**
- 공문·보고서·서식이 한글(HWP·HWPX)로 오가지만 AI 도구는 한글을 제대로 읽고 쓰지 못한다. 결과를 다시 한글로 옮겨 적는 일이 남는다.
- 서무 반복 업무: 받은 공문 회신, 부서 제출 양식 취합, 명단별 문서 작성, 정보공개 전 개인정보 가림, 결재용 합본 PDF.
- 업무망(폐쇄망)에서는 인터넷 AI 를 쓸 수 없고, 쓰더라도 개인정보·내부 문서 반출 우려가 있다.

**해결 방안**
- 작성: 기관 서식(HWP·HWPX)을 등록하면 누름틀 칸을 자동으로 찾아 내 기관 정보로 채우고, 빈 칸은 AI 가 참고 문서를 읽고 제안. 받은 공문 회신·민원 답변·회의록 초안.
- 편집: 앱에 들어 있는 한글 편집기(rhwp)로 그대로 고치고, AI 가 편집기 안 문단을 다듬는다. 공문서 표기법 검사(kordoc 4.21.18 기준 규칙 28가지와 "끝." 누락 확인).
- 출력: HWP·HWPX·PDF·인쇄·날인·공개용 사본·합본 PDF.
- 서무 일괄: 취합(양식 N개 → 엑셀), 명부로 여러 장, 개인정보 서식 보존 가림 + 잔존 재검사, PDF·스캔 → 한글, 신구대조표 한글 표.

**AI 활용**
- 이 PC 안 LLM(llama.cpp, GGUF), 기관 LLM 서버(OpenAI 호환) 연결, 클라우드는 선택(보내기 전 자동 가림). 이 PC 안 LLM 의 모델 파일(기본 추천 모델 약 2.3GB)은 설치 파일에 없어 처음 한 번 받거나 USB 로 반입한다.
- 문서 대화는 근거 문장 번호를 달고, AI 가 댄 인용이 원문에 실제로 있는지 대조한다.
- 이 PC 안 OCR(PP-OCRv5 korean)로 스캔 공문도 처리.

**기대 효과**: 앱의 효과 화면이 처리 건수 × 기준 시간으로 집계(기준 시간은 기관이 정한다). 시범 운영에서 실측해 채운다(지금 숫자를 지어내지 않는다).

**확산**: 설치 파일 하나(Node·엔진·OCR·편집기 동봉), 관리자 권한 불필요, 비용 0원(MIT), 기관 서식 등록 방식이라 기관별 개발이 필요 없다. 소스 공개(GitHub·공공 GitLab).

**필요 지원(안)**: 기관 LLM 서버 연결 시험 환경(AI 정부 실험실), 시범 기관 2~3곳의 서식·업무 협조.

## 4. 3분 시연 시나리오 (예제 문서 = 가상의 가온시)

1. (0:00) 설정 > 보안: 폐쇄망 모드 켬, "인터넷으로 나간 요청 0건". AI 는 이 PC 안 모델.
2. (0:20) 홈 > 예제로 해 보기 > 받은 공문에 회신: 가온도 공문 PDF → AI 회신 초안 → 기관 서식(간이기안문)에 내 기관 정보 자동 채움.
3. (1:00) 편집: 한글 편집기에서 문단 하나를 AI 로 "쉬운 공공언어"로 바꾸고 실행 취소까지. 표기법 검사 결과 누르면 그 문단으로 이동.
4. (1:40) 출력: HWP 저장 + 붙임과 합본 PDF(쪽번호).
5. (2:00) 취합: 다섯 부서 교육 수요조사서 → 엑셀 한 장.
6. (2:20) 개인정보: 정보공개 청구서 → 주민번호·연락처·계좌 서식 그대로 가림, 잔존 0건.
7. (2:40) 효과 화면: 오늘 처리 건수·아낀 시간(기준 시간은 가정치 표시), 다시 보안 화면 "인터넷 요청 0건"으로 맺음.
